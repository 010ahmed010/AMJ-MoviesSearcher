AMJ-MoviesSearcher - Docker Deployment Guide
===========================================

This project is now configured to run as a Docker container.

What this app is:
- Flask web app for searching multiple movie and series platforms
- Uses Python, Requests, and BeautifulSoup
- Runs in production with Gunicorn inside the container

Project structure for Docker:
- app.py
- Dockerfile
- .dockerignore
- requirements.txt
- .env.example
- templates/
- Functions/
- Test/

-----------------------------------------------------
1) Install Docker
-----------------------------------------------------
Install Docker Desktop or Docker Engine on your machine.

Check installation:
    docker --version
    docker compose version

-----------------------------------------------------
2) Create environment file
-----------------------------------------------------
Create a .env file in the project root with the same name you will use on the server.

Example:
    APP_ENV=production
    HOST=0.0.0.0
    PORT=8000
    SECRET_KEY=your-very-long-random-secret-key

You can copy from the example file:
    cp .env.example .env

-----------------------------------------------------
3) Build the Docker image
-----------------------------------------------------
From the project folder:
    docker build -t amj-moviessearcher:latest .

This uses the Dockerfile and installs all Python dependencies.

-----------------------------------------------------
4) Run the container
-----------------------------------------------------
Production-style container run command:
    docker run -d \
      --restart unless-stopped \
      --env-file /etc/amj-moviessearcher.env \
      -p 8000:8000 \
      --name amj-moviessearcher \
      amj-moviessearcher:latest

This means:
- app inside container listens on port 8000
- host exposes the same port 8000
- .env file is loaded from /etc/amj-moviessearcher.env

-----------------------------------------------------
5) Test the app
-----------------------------------------------------
Open in browser:
    http://localhost:8000/

Or from terminal:
    curl http://localhost:8000/

-----------------------------------------------------
6) Useful Docker commands
-----------------------------------------------------
View running containers:
    docker ps

Stop the container:
    docker stop amj-moviessearcher

Restart it:
    docker start amj-moviessearcher

View container logs:
    docker logs -f amj-moviessearcher

Remove container:
    docker rm -f amj-moviessearcher

Remove image:
    docker rmi amj-moviessearcher:latest

-----------------------------------------------------
7) Production notes for Docker
-----------------------------------------------------
- Keep SECRET_KEY real and unique
- Do not expose debug mode in production
- Use a reverse proxy or managed platform if needed
- For cloud deployment, you can push this image to Docker Hub or a registry

-----------------------------------------------------
7) Production notes for Docker
-----------------------------------------------------
- Keep SECRET_KEY real and unique
- Keep HOST=0.0.0.0 inside the container
- Keep the port mapping as 8000:8000
- Use a proper .env file such as /etc/amj-moviessearcher.env
- Run with --restart unless-stopped for reliability

-----------------------------------------------------
8) Final Docker example
-----------------------------------------------------
    docker run -d \
      --restart unless-stopped \
      --env-file /etc/amj-moviessearcher.env \
      -p 8000:8000 \
      --name amj-moviessearcher \
      amj-moviessearcher:latest

This is the recommended setup for your app.
